# Domain docs

- **Glossary**: `CONTEXT.md` at the repo root — a pure glossary, updated inline during grilling sessions. Challenge fuzzy terms against it; when a term is missing, pin it down and add it there.
- **Decisions**: `docs/adr/NNNN-slug.md` — written only when a decision is hard to reverse, surprising without context, and the result of a real trade-off.
- **Product truth**: `docs/SPEC.md` is the master spec (stack pins §3, conventions §6, definition of done §7, decomposition rule §8). `docs/ARCHITECTURE.md` covers runtime shape. Neither is a glossary — vocabulary goes to CONTEXT.md.
